# 数据集保存与恢复

工作台以results/数据名称为单位管理完整流程。首次保存扫描输入名称，或使用顶部新建数据集按钮。名称支持中文和空格，但不允许路径、Windows保留名称及保留字符。已有同名目录不覆盖创建，使用导入已有数据集继续。

阶段目录为setp1、setp2、setp3、setp4，dataset.json记录阶段更新与依赖状态。第五阶段只展示数据。导入时只选数据集根目录；不需要逐个导入阶段文件。界面顶部显示哪些产物存在且完整，缺失阶段可接着处理。各页按需加载已有结果，避免一次性读入全部大文件。

新setp1保存pointcloud_local/时间.npz和local_preprocessing.json，替代逐帧pointcloud_raw原始XYZ存档；局部包含清洗点、法线和表面标签，在IR局部坐标中保存，二阶段使用最终位姿融合。RGB/深度、标定、位姿和粗地图仍保存。旧数据集保持原样，不自动删除或转换pointcloud_raw。

二阶段在数据集模式下处理成功会自动保存，也可点击保存/覆盖本阶段重试。三、四阶段处理成功自动保存。重新拍摄保存到当前数据集会替换setp1；若要保留原扫描请先新建另一数据集。

覆盖操作写入数据集内独立临时目录。正式结果完整生成、后台成功结束、预览读回成功后才替换对应阶段，并更新数据集索引；异常、取消或索引写入失败回滚，保留旧产物。成功后清理本次临时及旧版本目录，不累计历史版本。不会删除其他数据集或其他阶段数据。

更新上游后，下游旧产物保留为可查看结果，状态标记需更新。只有按依赖顺序重新处理，状态才恢复；基于尚需更新的上游着色仍保留需更新标记。这个状态表示来源版本，不代表算法质量评分。

同一工作台不同时执行同一数据集的多阶段计算/保存。切换数据集须等待当前任务完成；有未保存扫描时先保存。不要从多个程序实例同时写入同一个数据集。

旧独立scan_*、setpN_时间目录不被批量迁移或覆盖，仍可在各阶段原导入入口使用；独立批处理脚本保留创建新时间戳目录行为。
