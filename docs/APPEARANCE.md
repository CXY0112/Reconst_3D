# 第四阶段：RGB顶点着色基线

当前默认已增加“覆盖恢复＋表面分区内小块颜色补全”。下文基础算法中的20mm/2像素为严格基线；增强模式采用25mm/3像素，并对额外观测降权至0.35。几何遮挡及深度跳变检查保持不变。历史结果兼容导入。

在主程序第四个选项卡使用，无需命令行参数。输入为第三阶段完整几何目录，依次从几何报告、预处理报告追溯原始扫描；丢失关联时可手动指定对应原始扫描。

这是可检查的顶点着色基线，尚未实现UV展开、图集或曝光补偿。输出保持第三阶段网格的顶点和三角连接，以及所有采集位姿。无需相机、模型训练、额外下载或新增运行环境。

## 算法

1. 严格通过最终几何位姿的节点ID → 接受配准记录 → 拍摄编号 → 帧时间戳，选择对应 `rgb/*.png` 和 `depth/*.png`。拒绝帧不参与。
2. 使用采集时已去畸变的RGB和对齐到RGB坐标系的毫米深度。最终位姿为世界坐标下的RGB光学相机位姿，内参取SDK RGB标定。IR外参只用于还原接口的坐标变换，不重复施加到配准RGB上。
3. 网格顶点投影到RGB，要求正深度、在图像边界内。最近有效深度只允许在2像素范围内填补小孔；3×3窗口深度跨度超过30mm时剔除，网格和深度差不超过20mm。
4. 剔除掠射观测（入射角余弦小于0.25）。网格射线检查第一次命中位置与待着色顶点的距离不超过6mm，避免把后方表面涂成前景色。
5. 双线性采样RGB，按入射角、距离、距图像边界的距离加权。先选择最高权重观测作为颜色锚点，再融合与锚点sRGB均方根差不超过0.18的观测；融合在线性RGB中进行，再转回sRGB。冲突观测计数保留，不直接平均成模糊色。
6. 未覆盖顶点保持灰色，不用生成颜色补齐未知区域。输入文件处理前后SHA-256一致才发布完整结果。

所有阈值为本次基线的工程选择，不是相机精度标定。颜色门限可能拒绝真实的光照变化，也无法保证检测所有错投影。法线使用绝对入射角兼容开放网格的法线方向，仍依靠深度和射线保证可见性。

## 输出与检查

数据集模式为`results/数据名称/setp4/`，同阶段成功重算后覆盖；独立批处理仍为`results/setp4_年月日_时分秒_微秒/`：

- `mesh_colored.ply`：包含sRGB顶点颜色的原网格；顶点颜色输出为PLY颜色通道，会有8位量化。
- `color_attributes.npz`：每顶点的覆盖标记、有效观测数、参与融合数、颜色冲突数、最高权重拍摄编号、最大颜色偏差。未覆盖处拍摄编号为-1。
- `report.json`：源几何、原始扫描、输入校验值、参数、每帧各级筛选数量、顶点覆盖率、三顶点均着色的面积比例、多视角颜色冲突比例及耗时。仅 `complete=true` 可作为正式结果。

界面右侧支持RGB、覆盖检查、灰色几何；左侧保持相同网格与同步视角。覆盖检查绿=至少一个可靠RGB观测，红=没有；融合面跨越未覆盖顶点时会出现灰色过渡。

顶点覆盖率与面积覆盖率不同。颜色冲突比例的分母为至少两次有效观测的顶点，不是全网格，也不是配准错误率。冲突可能来自光照、曝光、遮挡边界、标定误差或位姿误差。

## 当前预期

深度相机和RGB视场不同、遮挡和筛选均会造成灰色区域。减面后的顶点着色无法保留细小文字等高频纹理。若先验证出投影错位，应先检查标定、同步与位姿；UV贴图只能改善细节存储，不能修正错投影。覆盖率低则优先分析每帧筛选统计和补拍需求，不直接放宽所有阈值。以后再分别比较UV贴图、曝光校正与相机位姿微调的收益。

## 局部补色与几何表面分区

保留每顶点独立选择最高质量照片作为颜色锚点及原有多视角融合。得到真实观测颜色后，另做颜色补全，不改写已观测顶点的融合颜色。

- 只使用网格自身的边连接建图，边长最多50mm、相邻定向顶点法线夹角最多40度；图的连通分区是局部几何表面分区，不是语义物体识别。相接且法线相似的不同物体仍可能属于同一区。
- 对缺色连通块逐个检查：最多200顶点、关联表面面积最多25平方厘米、沿允许网格边到真实颜色锚点不超过40mm。
- 接触开放网格边界或非流形边的缺色块不补，避免扩展到无观测的大区域。至少3个真实颜色锚点；锚点颜色差异过大时保留缺色。
- 在线性RGB中求解逆边长加权的图拉普拉斯调和插值。固定真实颜色，只求缺色顶点；补全结果不会作为下一轮的真实锚点。
- 此方法适用于平滑颜色的小缺口；不合成缺失文字或重复纹理，不修补三角网格本身的几何孔洞。真正的物体分割与物体内纹理合成尚未实现。

新属性 `filled`、`display_covered`、`surface_region`、`observed_colors`、`strict_covered` 分别记录插值标记、最终显示覆盖、几何分区、插值前颜色、严格基线实测覆盖。原 `covered` 始终只表示真实RGB有效观测。

界面“RGB颜色”显示增强后的最终结果；“仅实测颜色”去掉插值；“覆盖检查”绿=实测、蓝=插值、红=缺色；“表面分区”显示几何分区。报告分别记录实测覆盖和插值后的显示覆盖，不能把补色数量解释为新增观测。
