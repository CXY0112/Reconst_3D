# RGB-D 场景工作流（2026-10-23）

默认启动 `python Reconst_3D/main.py`，精简演示使用 `python Reconst_3D/main.py beta`。`rgbd` 参数保留为默认入口的兼容别名。只有点击开始扫描才连接相机。

## 五个阶段

1. **采集**：原生 RTAB-Map RGB-D 视觉里程计、iSAM2 增量轨迹优化和局部体素子地图。保留 RGB-D、相机标定、位姿及点云；左侧完整场景，右上 RGB、右下实时彩色点云。
2. **预处理，可跳过**：卡尔曼表面融合、去重、表面均匀化、保特征精简及可见 RGB 关联。普通版输出体素和卡尔曼均匀间距默认均为 **2 mm**；平坦区域后续保特征精简仍使用原有 8 mm 策略，最终点间距并非全局固定为 2 mm。跳过只保存一阶段引用。
3. **几何重建**：默认 Poisson，另可选 TSDF／NKSR。只生成几何网格，**不再执行 RGB 上色**。TSDF 使用原始 SDK 深度、内参及位姿；NKSR 使用独立运行环境。普通版几何平滑默认 30 次。原始 RGB 及彩色点云仍保留，供查看、分割和 FAL 输入使用。
4. **场景分割／精细建模，可选**：两个选项卡为“物体分割”和“物体建模”。左侧默认显示灰色场景点云，已分割、当前选中和待应用框选区域通过颜色区分。RGB 照片支持滚轮切换，应用框选时可命名；物体列表仅包含编号、名称和点数。支持补入、移除、合并、撤销和保存。FAL 生成的模型独立查看、导出，**不再对齐、放回或替换原场景**。
5. **成果展示**：左侧默认“点云”（优先有效二阶段，跳过时为一阶段），可切换原始 RGB；右侧默认“几何网格”，可切换已下载的“精细物体模型”。独立物体使用独立视角，场景点云和几何可同步视角。顶部显示点数、减少百分比、几何三角面和已记录的几何覆盖指标；没有历史指标时显示未记录。

## Beta

Beta 仅显示拍摄／导入、场景分割／精细建模、成果展示。采集保存后自动执行卡尔曼预处理（输出体素 **1 mm**、均匀间距 **1 mm**），再执行 Poisson 几何重建（平滑 **20 次**），完成后进入展示。其他参数沿用默认设置；收费建模始终需手动提交。

Beta 只自动复用满足当前点云来源、1 mm／1 mm 预处理、Poisson 平滑 20 次且标明 `geometry_only` 的结果。旧流程结果可兼容查看；重新处理失败或取消时保留该阶段旧输出。

深色主题包含保存命名、分割命名、文件选择与确认弹窗。场景数据使用数字摘要及次级质量文字。启动前启用 Windows DPI 感知，按系统缩放绘制字体；字体显示更改需要关闭旧窗口并重新启动。普通 main 与 Beta 共用深色主题和弹窗样式，普通版保留五阶段设置入口。

## 云端物体模型

FAL 输入为选中照片、已保存实例掩码和 SDK XYZ 点图。点击收费提交后上传；随后自动查询同一任务并下载结果，不重复收费提交。已有本地模型查看不新建云端任务；网络失败使用退避重试并保留任务编号。

GLB 原始纹理保留；应用内以顶点采样颜色预览。查看和导出不改变场景网格。第五阶段可以浏览当前来源对应的各次已下载模型，数量表示模型文件份数，可能包含同一物体的多次生成。

## 数据目录与兼容

```text
results/数据名称/
  dataset.json
  setp1/                           # RGB-D、相机参数、位姿、融合点云
  rgbd_scene/
    setp2/                         # 彩色预处理，或跳过引用
    setp3/base/
      geometry/mesh.ply            # 无色几何出口
      report.json                  # geometry_only: true
    setp4/segmentation/             # 标签及来源引用
    setp4/fal/object_*/run_*/       # 任务输入、状态及原始 GLB
```

旧 `rgbd_scene/setp3/labels.npz` 和 `rgbd_scene/setp4/base` 兼容读取。旧彩色模型优先读取其对应 `geometry/mesh.ply`，并以无色几何展示。历史组合场景文件保留，但不再作为展示页的默认成果。导出数据集仍保留已有历史数据；API 密钥不写入数据集。

视图操作：WASD 前后左右、QE 上下、左键拖动转向、Z/C 滚转、R 或双击复位。采集页空格暂停／继续采样。

回归入口：`python Reconst_3D/tools/run_tests.py`。此轮使用现有数据进行几何实测与离线 UI 测试，未新增付费推理或导出源码包。
