# 几何重建模式

当前工作台提供Poisson、NKSR与SDK深度TSDF，默认Poisson；“几何方法对照”按钮和NoKSR重建入口已移除。三种模式统一保存mesh.ply/report.json，可进入RGB着色和展示。历史NoKSR输出仍可读取，不会自动覆盖或转换。

NKSR默认detail_level=0.4、mise_iter=1；不追加Poisson专用裁剪、平滑、减面和平面优化。正式批处理--method接受poisson、nksr或tsdf。

## 跳过二阶段与SDK直接TSDF

二阶段“跳过预处理”只保存complete/skipped与源扫描引用，不复制或改名保存一份“预处理”点云。数据集索引显示“已跳过”；事务替换、失败保留及下游需更新规则与正常处理一致。重新处理二阶段仍可恢复卡尔曼模式。

- Poisson：跳过时读取一阶段full_geometry_world.npy或map_cloud.ply。仅补算30mm/30邻居PCA法线，按最近保留相机定向；不移动、融合或降采样输入点。随后仍走下面完整Poisson流程。最近相机法线定向是工程启发式，不保证所有遮挡表面的法线正确。
- NKSR：需要正常二阶段点云/法线；跳过后选择NKSR会明确提示，不能静默改用另一算法。
- TSDF：读取全部保留观测的depth_raw、RGB内参和位姿。使用5mm体素、30mm截断、4m深度上限、ScalableTSDF depth_sampling_stride=1，不添加网格平滑或减面。先抽查首、中、末观测的SDK XYZ投回原深度，至少100点且90%在10mm内才运行；此核验不等于完整相机标定验证。

本机已核对SDK深度/XYZ匹配RGB内参网格；TSDF等价世界位姿为P_saved×E，保持原世界点云关系，不重估或改写源位姿。不同SDK配准模式核验失败时停止，不猜测IR内参或静默改用其他深度。TSDF报告camera_model=sdk_rgb_grid_v1，第四阶段使用相同深度与等价位姿，避免回到旧注册深度坐标。

TSDF总是直接使用一阶段深度，即使输入来源指向已处理的二阶段，也不会把融合点云回投为稀疏深度。报告明确preprocessing_used=false。没有depth_raw、内参或保留观测来源时拒绝TSDF；单独PLY不足。所有方法的自身input_coverage取决于其输入点集，比较多条流程应另用同一参考点集，不能直接混比报告中的百分比。

日常入口：`python Reconst_3D/main.py`，切换“三阶段 · 几何重建”。可从第二阶段保存后直接进入，或导入已有卡尔曼预处理目录。左侧输入点云，右侧真实三角网格，支持线框、同步视角和视点移动。后台运行可取消，完成自动保存，支持重新导入结果。

无窗口批处理仍可无参数启动：`python Reconst_3D/tools/reconstruct_geometry.py`。

默认寻找最新的完整卡尔曼预处理目录，要求同目录有`processed_world.npy`、`surfel_attributes.npz`中的`normals_world`以及`report.json`。不依赖早期几何实验目录，不连接相机。已知预处理点云保持原分辨率，不再降采样作为Poisson输入；仅平面检测使用15mm临时体素。

## Poisson默认流程

1. Poisson：depth=9、scale=1.05、4线程，沿用当前几何基线。
2. 观测支持裁剪：三角面所有顶点及中心距输入点云≤15mm。
3. 受约束Taubin：30轮，λ=0.45、μ=-0.47；固定边界与≥65°锐边，累计移动≤8mm，翻面回退。
4. 分连通片QEM：不足1000面的连通片完整保留。先申请原支持网格总面数的40%，扣除保留部分后，向大连通片分配预算。检查失败依次50%、60%、70%、80%、90%、100%，不越过候选，不隐藏追加代数误差组合。实际面数受整数分配和QEM约束影响，不保证精确命中。
5. 平面感知：复用原始观测、法线、点云对象和空间索引，沿用已有平面检测/主平面提取/双层及曲率检查；每个顶点新增位移≤8mm，相对裁剪原网格固定锚点≤15mm。保留减面后的三角形连接。
6. 最终验收与导出：检查整个输出相对裁剪原网格的双向抽样偏差和面积变化；平面校正若使验收失败，依次减少其作用强度至0，保留通过检查的减面网格。报告实际采用的强度，不静默宣称全部平面校正已应用。

减面和最终验收沿用15mm双向抽样最大距离、面积变化≤5%的条件。每方向按表面积抽样100,000点；原网格查询结构和样本复用。这些检查不是精确Hausdorff距离或真实精度保证。平滑/平面校正检查局部翻面，QEM本身仍可能改变局部拓扑。最终输入点到网格的距离仅在末尾统计一次。

## 输出与查看

数据集模式覆盖保存至`results/数据名称/setp3/`；独立批处理新建`results/setp3_时间/`。默认只有：

- `mesh.ply`：最终三角网格，米，世界坐标X前/Y左/Z上。
- `report.json`：输入校验值、各阶段数量和耗时、每次减面尝试、平面拟合与最终验收记录、最终网格校验值。`complete=true`才是成功结果。

`--source 路径`和`--output 新目录`可用于复现指定数据；输出不可位于输入目录内，已有目录不覆盖。`--debug`才保存中间网格到`debug/`。这类参数用于指定数据/诊断，不再用于切换重建方法。

在第三阶段使用“导入重建结果”查看三角网格；第五阶段可同时查看最终RGB网格与其上游源数据。支持视角联动和WASD/QE移动。旧实验独立查看器已归档。

工作台中的临时预览数据在后台任务结束后清理，不放入正式结果目录；查看器读取新`setp3_*`和旧`geometry_final_*`。一、二阶段分别保存为`setp1_*`、`setp2_*`，历史目录不迁移。

## 首轮真实数据验证

输入`kalman_uniform_scan_20261015_102420`的582,341点。首轮正式结果`geometry_final_20261015_162912_357207`：

- 40%候选首次通过，输出162,709顶点、295,276三角面，约保留裁剪网格40%，减少约60%。
- 核心处理26.14秒（不含工作进程启动及库导入）；各阶段实际耗时见其`report.json`。并未将历史双分支实验耗时当作同条件单路基准，因此不报告未经实测的加速倍数。
- 最终网格相对裁剪原网格的双向抽样最大距离12.18mm，面积比例0.9831；匹配平面顶点到拟合平面P90由8.44mm降至2.13mm。
- 独立对比旧7与本轮输出：双向面积均匀抽样P90距离0.22mm、P99为1.13mm、抽样最大值9.94mm；这是对旧输出的一致性，不是真实场景误差。
- 保存文件仅最终网格和JSON报告。正常流程不运行BPA、不逐阶段渲染比较图、不反复导出/读取网格。

线程调度、浮点求解和抽样会导致少量结果差异，应以每次输出自己的报告为准。

完成空间索引复用和启动耗时记录后的正式复测：`geometry_final_20261015_163659_240830`。40%候选首次通过，162,703顶点、295,278面；核心25.50秒，含工作进程启动28.58秒。最终相对裁剪网格双向抽样最大距离10.65mm，输入点到网格P90为10.15mm，已匹配平面顶点残差P90为8.35→2.08mm。该次结果为当前默认查看输出。
