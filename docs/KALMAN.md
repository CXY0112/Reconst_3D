# 卡尔曼表面融合

二阶段默认且唯一公开算法，从接受的局部观测融合，不重跑PointDSC/ICP，不修改保存位姿。新扫描在一阶段完成局部清洗和法线估计；旧扫描兼容原始SDK点云离线处理。通过main.py二阶段或preprocessing/main.py使用，默认输出采用表面均匀采样。

## 输入

导入扫描目录或其中map_cloud.ply。需要pointcloud_local（新）或pointcloud_raw（旧），以及sdk_calibration.json、geometry_poses.json、frames.jsonl和registrations.jsonl。新格式另外保存local_preprocessing.json，局部包为米制IR相机坐标，包含点、法线、有效性和边界标签以及处理参数/统计。不保存被剔除点坐标；不是全局融合点云的切片。独立PLY不足以重新融合局部观测，缺失数据明确报错。

通过接受节点、拍摄编号、时间戳和原始文件绑定观测，跳过未接受拍摄。不得将所有原始文件与接受位姿直接顺序配对。

## 流程

1. 新扫描直接读取一阶段的压缩局部表面包；旧扫描先进行5mm体素归并、孤立点清洗和局部表面估计。两条路径共享同一局部处理实现，防止算法分叉。
2. 按标定和最终拍摄位姿变换局部点与法线；新扫描不重复局部拟合。拟合邻域/邻居数与采集时一致，修改二阶段容忍尺度只影响融合与方差，输出体素只影响最终密度归并；采集时局部清洗参数在报告中单列，不能从已丢弃XYZ重新拟合。
3. 对相近且法线、层面一致的表面元进行关联。沿法向做标量卡尔曼更新，按观测方向和深度估计测量方差；同帧相关采样不重复增加置信度。限制方差下限和相对锚点累计位移。
4. 对相反朝向、明确分层和边缘采取保守保护，不能关联的观测保留为独立表面元。
5. 默认使用表面感知均匀采样，以切向间距减少过密点，避免跨层/锐边直接合并。处理半径和均匀间距独立设置，默认表面间距5mm。

## 输出与限制

数据集模式保存到数据名称/setp2（旧独立导入可另存setp2_时间）：processed.ply、processed_world.npy、surfel_attributes.npz与report.json。表面属性包括一一对应的法线、support_views、sigma_normal_mm。诊断文件的索引及位移含义以报告为准，不应视为最终点云与输入的简单一一对应。

不修改原始扫描和拍摄位姿。保留未被多视角覆盖的单次观测；方差和支持次数不是绝对精度承诺。局部关联与法线门控是启发式，无法可靠区分全部小于噪声尺度的薄结构；系统性偏差与真实分层不会自动消失。必须结合边缘、覆盖和空间截面检查，不能仅凭点数减少判断质量提升。

处理和取消在后台执行，保存时成功清单最后写入。只有完整保存结果才能进入第三阶段。历史对比报告保存在results，旧实验代码已移出正式目录。
