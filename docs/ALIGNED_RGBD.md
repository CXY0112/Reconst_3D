# 完整场景彩色点云分支（rgbd）

> 维护状态：独立像素对齐实验窗口已移除；pointmap_processing.py 中当前采集仍用到的深度反投影和 SDK 网格核验继续保留。 以下历史实验记录不作为当前界面操作说明。

启动：`python Reconst_3D/main.py`；`rgbd` 是同一入口的兼容别名。默认与 Beta 均使用完整彩色场景数据链。当前五阶段顺序见 [彩色场景工作流](SCENE_WORKFLOW.md)。

二阶段可跳过；三阶段为整场景彩色重建；第四阶段为 MobileSAM RGB 框选提示分割与可选 FAL 精细建模，不再使用自动 SuperCluster 分割。
二阶段跳过仅保存原始场景引用；第四阶段可直接使用一阶段点云和保留的 RGB-D／位姿。

一阶段复用原main的RTAB-Map视频定位和增量地图：左侧完整融合场景，右上实时RGB，右下实时RGB真彩点云。采集、暂停/继续、保存命名、导入和相机位姿沿用原实现。全图着色在后台计算，latest-only任务队列避免排队；未完成时保留最近彩色地图，全图着色仍有额外计算延迟。

rgbd分支的稠密更新现默认使用[局部体素子地图](SUBMAPS.md)：最多8帧一组，历史共同刚体修正只移动子地图，内部变形只重建受影响组。实时全局3mm去重；完成时从帧级观测及最终位姿生成精确全局结果，二阶段入口不变。普通版/Beta暂保留全局体素后端。全图RGB着色及完整数组显示仍有开销，尚未实现空间块增量显示。

一阶段的“轨迹优化”可选“当前默认方案”或“iSAM2（增量优化）”，开始扫描前选择，采集中锁定。默认方案保持原生默认设置；本机已核验为GTSAM批量优化。iSAM2通过同一RTAB-Map后端启用`Optimizer/Strategy=2`、`GTSAM/Incremental=true`、Gauss-Newton、重线性化阈值0.01、检查间隔1。只替换位姿图优化，RGB-D视觉里程计、回环检测、稠密融合和二阶段处理链不变。此选择仅展示在rgbd分支，普通版和Beta不新增控件。

保存的数据集setp1内，`video_capture.json`记录用户选择，`optimizer.json`记录原生初始化确认，`map.db`的Info参数记录实际配置。选择iSAM2而运行库不支持时明确报错，不自动退回默认方案。仅导入已有地图查看，不会重算其历史位姿；要比较两种方案需分别采集，或用同一RGB-D序列离线对照。移植时需要带GTSAM支持的RTAB-Map开发/运行库，并重新编译桥接与主机；仅复制Python文件不足以启用原生选项。

离线验证入口：`python Reconst_3D/tools/validate_isam2.py --output <新的实验目录>`。合成视角和稀疏保存关键帧仅用于接口与时延诊断，不代表真实连续视频精度或长期扩展性。首轮记录见`results/experiments/isam2_validation_20261021/REPORT.md`。

二阶段只显示左右两个同等大小的完整场景点云：左侧未处理RGB点云，右侧预处理后RGB点云。没有切帧、单帧清洗或右侧拆分照片。复用原工作台视角控制和同步视角。

处理包括：局部孤立点清洗、固定相机位姿下的卡尔曼表面融合、体素去重、表面均匀重采样，以及保特征精简。融合沿用原normal/tangent/层间约束、同帧一次更新和10mm位移上限。精简根据法线变化、邻域曲率、线状结构及稀疏区域识别特征，扩展6mm保护带；保留全部检测特征，平坦区以8mm目标间距选择原点，不继续移动点位置。特征是保守启发式判断，不是语义分割，也不保证找出全部真实边缘。

颜色来自通过30mm深度可见性检查的最佳原始RGB照片，不做跨物体颜色平均，无实测颜色点用灰色并记录有效标记。为左侧完整场景补RGB不会改变几何或点数。

输入需包含一阶段RGB-D、内参、位姿、原始观测和接受清单。单独PLY或旧逐帧导出缺少位姿，无法可靠地恢复全局关系，界面会报错。

结果存入当前数据集的`rgbd_scene/setp2`，隔离普通版原setp2。processed.ply和processed_colored.ply包含XYZ/RGB；processed_world.npy为同一份几何；surfel_attributes.npz包含法线、支持帧数、不确定度、RGB、特征保护标记，以及颜色来源capture/UV。重新导入整个数据集自动恢复；再次处理成功后覆盖彩色分支setp2，失败/取消保留旧结果。

去重和精简后，全局点与原照片像素不再是一一关系。后续若要向fal提供点图，应从处理后的完整场景按选定相机位姿重投影，并处理遮挡；不能将N×3全局点云直接当作H×W像素点图。本界面不发送云端请求。

实测见results/experiments/test_new_colored_scene_20261020/REPORT.md。历史单帧试验输出仅留档，不代表当前流程。
